- hdash: the Corpus tag filter is a multi-select (several tags, ANDed) and lists the hive's tags every time the page opens; it used to stay empty after the first visit. Bare numbers and sha-like ids are hidden by default (a toggle shows them). With two or more tags the page reads the first tag's search and keeps the rows that carry all of them, up to 1000 results, and says so when it stops.
