- hdash 4.x: config forms on hconfig. Settings › Node and each module's Config tab render `hconfig list --json` records (`GET /api/settings`); `POST /api/settings` runs `hconfig set` with the value on stdin only, behind the Host/Origin/CSRF guard plus a loopback-source check and a refusal of any `Tailscale-*` header (hive-mind#100 gates 6a–6c). `core:` keys and `node:owner_quota` are read-only with the command to copy; an owner-writable module key is signed by the core through the unlock agent or shows the `owner-locked` unlock hint. hdash signs nothing and never holds the passphrase.
