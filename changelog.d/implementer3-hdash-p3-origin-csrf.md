- hdash P3: a Host/Origin check and CSRF on every state-changing route. A non-GET request must carry the loopback Host, an `Origin` equal to the listener's own origin (absent or `null` is refused), `Sec-Fetch-Site: same-origin` when the browser sends one, the per-process token from `GET /api/csrf` in `X-HDash-CSRF` (constant-time compare), a JSON content type and a body of at most 64 KiB; only then is a write route looked up, and a refused write closes the connection. A GET with a foreign `Origin` or `Sec-Fetch-Site: cross-site` is refused too. OPTIONS is never answered with CORS. hdash still has no write route: the guard lands before the first one.
