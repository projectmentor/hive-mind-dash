- hdash 4.x P4, viewer mode: `hdash share [--allow LOGIN] [--port N]`, `unshare` and `viewers` publish a read-only dashboard to allowlisted tailnet logins through `tailscale serve` on HTTPS 8443. The viewer listener is hdash's own (default `127.0.0.1:9906`, bound only while the node key `dashboard_share` is on, never falling back to another port), with its own gate (exactly one listed `Tailscale-User-Login`, `GET` only, a read-only path subset, `403 {"listener": "viewer"}` otherwise, no source-address trust), its own rate limit and slots, and a short cache that bounds hdash's calls to the core on a viewer's behalf. `GET /api/config/records` serves a viewer the non-identifying governed values and `viewer: true` module values, never a `node:` key or a secret. `share` checks the viewer port against hdash's operator port, the daemon's live port, `range(base, base+5)` and the module API port, and probes the loopback port for the viewer signature before it touches Serve; the new `hdash doctor` row `dashboard-exposure` repeats the checks and fails on Funnel for 8443. The page enters a viewer mode off loopback. Writes go through `hv config node set`. Needs hive-mind 4.0 (`dashboard_share` node key).
